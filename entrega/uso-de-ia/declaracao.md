# 1. Ferramenta utilizada
- Ferramenta: ChatGPT
- Modelo: GPT-6

# 2. Como utilizei a IA

Durante o desenvolvimento do projeto, utilizei o ChatGPT como ferramenta de apoio para compreender a organização das pastas, configurar o ambiente, executar e interpretar os testes automatizados e entender conceitos de Python relacionados aos defeitos encontrados, como conversão de moedas, `Decimal`, `datetime` e ordenação de listas.

Também utilizei a IA para esclarecer dúvidas, analisar possíveis causas dos erros e auxiliar na elaboração de toda a documentação da entrega.

# 3. Divisão das atividades

- IA: explicou conceitos, auxiliou na interpretação dos erros, apresentou exemplos e sugeriu possíveis soluções.
- Minha participação: executei os comandos, analisei o código, investiguei os problemas, implementei as correções e validei os resultados por meio dos testes automatizados.
